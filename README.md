# IOS_challenge - Cardamomo
## Sobre el proyecto
Para el proyecto quise realizar una app que permitiera facilitar el uso de la cocina para cualquier persona. Pues algo que siempre me pasa es que llego de la escuela / de hacer pendientes y tengo que cocinar algo para comer, pero no tengo ni el conocimiento ni la creatividad suficiente para crear platillos con lo que tengo disponible. Entonces, por medio de esta app, espero facilitar el proceso para gente que, al igual que yo, ve los ingredientes que tiene en su refrigerador y no sabe cómo combinarlos.

Con esto en mente, quisiera recalcar que esta app se distingue de otras que realizan recomendaciones de recetas con base en ingredientes porque, mediante el contexto de [RecetasDeLaAbuela](https://huggingface.co/datasets/somosnlp/RecetasDeLaAbuela) y el poder de foundation models, Cardamomo provee una perspectiva más mexicana y tradicional de qué recetas puede realizar uno.

Gracias por leer! :D
